# Manyaleza Suppliers Website (mock-data build)

React + Vite + Tailwind CSS catalogue and WhatsApp-enquiry site.

    npm install
    npm run dev       # local preview
    npm run build     # production build in dist/ (deploy to Vercel)

All products, prices and copy live in `src/data.js` and are MOCK DATA.
Reconfirm the WhatsApp number (`BUSINESS.wa`) and replace sample content before launch.
Firebase/admin dashboard is not wired in yet (optional per proposal scope).
